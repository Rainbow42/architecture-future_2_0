# Технологический стек и экономика

Подготовила решения по стеку, трёхлетнее сравнение стоимости и переход к Data Mesh.

- [Техрадар](tech-radar.md): технологии и подходы, кольца Adopt / Trial / Assess / Hold, основания и условия пересмотра.
- [TCO as-is / to-be](tco-analysis.md): инфраструктура, лицензии, эксплуатация, время аналитиков, переход и чувствительность.
- [Исходные допущения расчёта](cost-model.json).
- [Роадмап Data Mesh](roadmap.md): этапы, роли и критерии выхода.

Числа в TCO — учебные допущения, не реальные счета или предложения поставщиков. На этих допущениях переход не окупается за три года только за счёт экономии затрат; этот результат не скрываю.

Воспроизвести расчёт и проверить таблицы:

```sh
node scripts/calculate-tco.mjs
node scripts/calculate-tco.mjs --check
```

Раздел описывает проектное решение. Бюджет, сокращение рутины и организационные изменения на практике не подтверждены.
