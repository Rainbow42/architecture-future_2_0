# Одиннадцатый спринт

Проект для компании «Будущее 2.0»: переход от общего DWH к доменной событийной архитектуре и самообслуживанию в аналитике.

Работа в процессе, к сдаче не готова. [Требования и порядок работы](docs/plan.md).

| Каталог | Содержание |
|---|---|
| Task1Advanced | Terraform-модуль ВМ и окружения dev, stage, prod |
| Task2Advanced | Удалённое состояние и CI/CD |
| Task3Advanced | C4, риски и меры снижения |
| Task4Advanced | Bounded contexts, агрегаты и события |
| Task5Advanced | Техрадар, TCO и роадмап |

Медицинские карты, истории болезней и результаты исследований не входят в аналитическую витрину. Доступ к медицинским данным для лечения и ИИ должен остаться в отдельном операционном контуре.

Реальные облачные ресурсы не создавались. Проверки без обращения к облаку не заменяют проверку развёртывания.
